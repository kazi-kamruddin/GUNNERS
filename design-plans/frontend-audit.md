### Cross-Cutting Failure Themes
1. **Accessibility & Keyboard Traps (`10` findings across shell, pitch, lab, terrace, messages, profile):** Missing `<1024px` mobile navigation (`ED-P0-01`), WCAG AA contrast failure on `text-accent` small text (`3.34–3.83:1`) and `text-error` (`4.36:1`) (`ED-P0-02`), `TacticalBoard` `focus:outline-none` & `role="application"` (`INT-P0-03`), `/terrace` guest `onfocus` keyboard trap & nested `role="button"` lightbox (`COM-P0-2`), and 5 modals/drawers lacking `role="dialog"`, focus trap, `Escape`, and trigger-focus restoration (`INT-P0-05`, `INT-P1-05`, `COM-P0-2`, `COM-P1-5`).
2. **Honest API Resilience & Render ~50s Cold-Start Feedback (`7` findings):** Silent fallbacks fabricating future fixtures/news (`ED-P0-03`), swallowing HTTP errors as `"No players found"` / empty leaderboards / empty analytics (`ED-P0-03`, `INT-P1-06`, `INT-P1-12`), throwing false `404` on HTTP `500`/timeout (`ED-P0-03`), and blocking navigation with no `navigating` indicator (`ED-P0-03`).
3. **Mobile Breakpoint Failures at `320px` / `390px` / `768px` (`11` findings):** Missing mobile header nav (`ED-P0-01`) + silent `768–1024px` nav clipping (`ED-P1-01`), `/predictions` `grid-cols-7` scoreline input overflow (`INT-P0-01`), `/messages` stacked `640px` inbox/thread trap (`COM-P0-1`), `/board` `touch-none` scroll trap & 0px drag threshold (`INT-P0-02`), `/matches` row crushing (`ED-P1-03`), `/news` pill clipping (`ED-P1-04`), and `/lab` ~4.6px SVG chart labels (`INT-P1-08`).
4. **Svelte 5 SSR & State Integrity (`6` findings):** `$effect`-only initialization violating Hallmark Floor #7 on `/board`, `/lab`, `/lab/historical`, `/predictions` (`INT-P0-07`), one-shot `if (!initialized)` filter locks (`ED-P1-04`, `ED-P1-05`), and stale `metric`/`venue` saved inside `Insight` snapshots (`INT-P0-04`).
5. **Auth & Session Hardening (`6` findings):** `GET /auth/signout` CSRF/prefetch logout + `+layout.ts` `getSession()` desync (`COM-P0-3`), dropped `?next=` redirects (`COM-P1-6`), missing `emailRedirectTo` & recovery hash race (`COM-P1-8`), and `/profile` avatar upload/overwrite issues (`COM-P1-9`).
6. **Domain Truth & CRUD Parity (`6` findings):** Pruned/departed Arsenal players in `TacticalBoard` & `football.ts` (`INT-P1-01`), `"GUNNERS REBORN"` PNG banner + missing vector arrows (`INT-P1-02`), missing owner `DELETE` UI on `/board` and `/lab` (`INT-P1-03`, `INT-P1-11`), broken `author_name` vs `username` links & self-DM 400 (`COM-P1-2`), and `/terrace` photo-only Publish no-op (`COM-P1-1`).
